# SIDOMAS Kota Pekalongan

## Apa itu SIDOMAS Kota Pekalongan

SIDOMAS adalah kepanjangan dari (Sistem Data Organisasi Masyarakat dan Partai Politik).
Sistem ini merupakan Projek dari Badan Kesatuan Bangsa dan Politik Kota Pekalongan untuk mendata Ormas (Organisasi Masyarakat) dan Parpol (Partai Politik) di Kota Pekalongan.

Sistem ini dikembangkan berbasis Website agar dapat mudah diakses dan digunakan oleh pengguna umum melalui jaringan internet.


Pengembang : MB Digital
Bahasa Pemrograman : PHP
Database : MySQL
Library : Codeigniter 4, jQuery, Bootstrap 5, dll.
